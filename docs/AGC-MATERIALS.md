## 二、应用介绍

**长版（约 480 字，适配 800 字以上上限）**

```
「口袋键鼠」把你的鸿蒙手机变成电脑的无线外设：触摸板、全键盘、语音听写三合一，局域网内直连，低延迟，无需账号。

主要功能
· 触摸板：单指滑动移动光标、轻点即左键；双指滑动滚动、双指轻点右键；灵敏度与自然滚动可调。
· 全键盘：手机上弹出完整键盘，为电脑输入中英文与符号，支持回车、退格与方向键等常用按键。
· 语音听写：按住麦克风说话，识别结果直接输入到电脑，适合快速记录。
· 多主机管理：可配对多台电脑并随时切换，默认主机自动重连。

使用方式（重要）
本应用需配合电脑端开源守护进程使用：在电脑（Ubuntu / macOS）上执行一行命令安装 padlinkd 后，手机与电脑处于同一局域网即可搜索配对。安装方法与源码见应用内「设置 → 服务端安装指南」及 GitHub 项目主页。

隐私说明
无账号、无云端服务器，所有数据仅在你的手机与自己的电脑之间传输；语音仅在按住说话期间录音并即时识别为文字；不收集任何个人信息，不含广告与第三方统计组件。
```

**短版（约 190 字，适配 200–500 字上限）**

```
「口袋键鼠」把手机变成电脑的无线触摸板、键盘和语音听写器：局域网直连、低延迟、无需账号。在电脑安装开源守护进程（一行命令，支持 Ubuntu 与 macOS）后，手机即可移动电脑光标、输入中英文、按住说话把文字上屏到电脑，并可配对多台电脑随时切换。全部数据仅在你自己的设备之间传输，不收集任何个人信息。
```

## 六、数据披露（AGC 隐私声明/数据安全）

【电脑端获取】开源地址：https://github.com/Norman-pong/padlink 。GitHub Releases 提供 Ubuntu 与 macOS 安装包（tar.gz 内含 install.sh 一键安装；Ubuntu 另有 deb/rpm）。应用内「设置 → 服务端安装指南」提供同一条安装命令。

## 十、演示视频分镜（约 60 秒，可直接照拍）

> 拍摄建议：手机自带录屏（控制中心 → 屏幕录制）+ 电脑侧录屏（QuickTime / GNOME 录屏）后期并排或画中画；也可直接用相机拍"手机 + 电脑屏幕同框"。评审看的是"功能真实可用"。
> 需要真人语音的只有第 5 段；其余段落可用本文件给出的示例文案操作。

| 段 | 时长 | 画面 | 操作要点 |
| --- | --- | --- | --- |
| 1 | 5s | 电脑端 | 终端执行 `padlinkctl status`，显示 daemon 运行中（macOS 亦可 `launchctl print gui/$UID/com.zhimingcool.padlink`） |
| 2 | 10s | 手机 + 电脑 | 手机「连接主机」→ 选中电脑 → 电脑显示 4 位确认码（桌面通知）→ 手机输入 → 显示"已连接" |
| 3 | 15s | 手机 + 电脑 | 单指滑动（电脑光标连续移动）、轻点（左键）、双指滚动（页面滚动）、双指轻点（右键菜单） |
| 4 | 10s | 手机 + 电脑 | 点右下角键盘键 → 输入 `用手机给电脑打字，很方便` → 电脑文本编辑器逐字上屏 |
| 5 | 10s | 手机 + 电脑 | 按住麦克风说一句（如"你好，这是语音听写"）→ 松手后文字上屏电脑 |
| 6 | 5s | 手机 | 设置页拖动灵敏度滑杆（可选：多主机列表切换） |
| 7 | 5s | 字幕卡 | 电脑端下载地址：github.com/Norman-pong/padlink |

> 录制能力说明：手机侧系统未提供可脚本化的录屏（`screenrecord` 不可用），本机进程也没有 macOS 屏幕录制权限，故视频需人工拍摄。若给 ZCode/终端授予「屏幕录制」权限，电脑侧画面可由脚本自动录制。
