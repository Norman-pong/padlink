## 二、应用介绍

**长版（约 480 字，适配 800 字以上上限）**

```
「口袋键鼠」把你的鸿蒙手机变成电脑的无线外设：触摸板、全键盘、语音听写三合一，局域网内直连，低延迟，无需账号。

主要功能
· 触摸板：单指滑动移动光标、轻点即左键；双指滑动滚动、双指轻点右键；灵敏度与自然滚动可调。
· 全键盘：手机上弹出完整键盘，为电脑输入中英文与符号，支持回车、退格与方向键等常用按键。
· 语音听写：按住麦克风说话，识别结果直接输入到电脑，适合快速记录。
· 多主机管理：可配对多台电脑并随时切换，默认主机自动重连。

使用方式（重要）
本应用需配合电脑端开源守护进程使用：在电脑（Ubuntu / macOS）上执行一行命令安装 padlinkd 后，手机与电脑处于同一局域网即可搜索配对。安装方法与源码见应用内「设置 → 服务端安装指南」及 GitHub 项目主页。

隐私说明
无账号、无云端服务器，所有数据仅在你的手机与自己的电脑之间传输；语音仅在按住说话期间录音并即时识别为文字；不收集任何个人信息，不含广告与第三方统计组件。
```

**短版（约 190 字，适配 200–500 字上限）**

```
「口袋键鼠」把手机变成电脑的无线触摸板、键盘和语音听写器：局域网直连、低延迟、无需账号。在电脑安装开源守护进程（一行命令，支持 Ubuntu 与 macOS）后，手机即可移动电脑光标、输入中英文、按住说话把文字上屏到电脑，并可配对多台电脑随时切换。全部数据仅在你自己的设备之间传输，不收集任何个人信息。
```

**套壳脚本（改样式时用，原图在 `docs/agc/raw/`）**

```python
# 依赖：pip install pillow（本机已装）
from PIL import Image, ImageDraw, ImageFilter

CANVAS, BEZEL, DEV_W, RADIUS = (1080, 1920), 26, 1000, 66
SRC = {  # 输出文件名: 原图路径
    '01-触摸板.png': 'docs/agc/raw/01-触摸板-原图.png',
    '02-键盘.png': 'docs/agc/raw/02-键盘-原图.png',
    '03-语音听写.png': 'docs/agc/raw/03-语音听写-原图.png',
    '04-已配对主机.png': 'docs/agc/raw/04-已配对主机-原图.png',
    '05-服务端安装指南.png': 'docs/agc/raw/05-服务端安装指南-原图.png',
    '06-设置（备选，含调试项）.png': 'docs/agc/raw/06-设置-原图.png',
}

def bg(size):  # 浅色纵向渐变，可换品牌蓝等
    top, bottom = (240, 244, 250), (219, 228, 240)
    im = Image.new('RGB', (1, size[1]))
    for y in range(size[1]):
        t = y / (size[1] - 1)
        im.putpixel((0, y), tuple(round(top[i] + (bottom[i] - top[i]) * t) for i in range(3)))
    return im.resize(size, Image.BILINEAR)

for out, src in SRC.items():
    shot = Image.open(src).convert('RGB')
    cw = DEV_W - 2 * BEZEL
    ch = round(shot.height * cw / shot.width)
    dev_h, x, y = ch + 2 * BEZEL, (CANVAS[0] - DEV_W) // 2, 0
    y = (CANVAS[1] - dev_h) // 2
    canvas = bg(CANVAS)
    sh = Image.new('L', CANVAS, 0)
    ImageDraw.Draw(sh).rounded_rectangle([x + 6, y + 16, x + DEV_W - 6, y + dev_h + 12], radius=RADIUS, fill=64)
    canvas = Image.composite(Image.new('RGB', CANVAS, (124, 134, 148)), canvas, sh.filter(ImageFilter.GaussianBlur(24)))
    d = ImageDraw.Draw(canvas)
    for ex, y0, y1 in ((x, 300, 372), (x, 402, 474), (x + DEV_W, 344, 436)):  # 音量×2 / 电源
        d.rounded_rectangle([ex - 3, y + y0, ex + 4, y + y1], radius=2, fill=(64, 66, 70))
    d.rounded_rectangle([x, y, x + DEV_W - 1, y + dev_h - 1], radius=RADIUS, fill=(23, 24, 26), outline=(62, 64, 68), width=1)
    scaled = shot.resize((cw, ch), Image.LANCZOS)
    mask = Image.new('L', (cw, ch), 0)
    ImageDraw.Draw(mask).rounded_rectangle([0, 0, cw - 1, ch - 1], radius=RADIUS - BEZEL, fill=255)
    canvas.paste(scaled, (x + BEZEL, y + BEZEL), mask)
    canvas.save(f'docs/agc/screenshots/{out}', 'PNG', optimize=True)
```

## 五、权限用途说明（AGC 权限填报）

包内声明（`entry/src/main/module.json5`）：仅 `ohos.permission.MICROPHONE` 为 user_grant，其余为 system_grant。

| 权限标识 | 级别 | 用途文案（照抄） |
| --- | --- | --- |
| `ohos.permission.MICROPHONE` | user_grant | 麦克风权限仅用于「按住说话」语音听写：按住期间录音并识别为文字输入到电脑。 |
| `ohos.permission.INTERNET` | system_grant | 与用户同一局域网内的电脑通信（发现、配对与数据传输）。 |
| `ohos.permission.GET_NETWORK_INFO` | system_grant | 读取本机网络状态以完成局域网主机发现。 |

> **打回经验（2026-10-12 实测）**：AGC 会自动比对「包内 user_grant 权限」与「托管隐私政策文本里出现的权限」，不一致即打回，报错形如
> `检测到当前软件包user_grant类型的权限与隐私政策中声明的权限不一致，请修改后提交。只在软件包中的权限：[MICROPHONE]`。
> 隐私政策里**必须出现权限标识原文**（如 `ohos.permission.MICROPHONE`），只写中文"麦克风"不算——`PRIVACY.md` 第二节已按此列出全部权限标识。
> 改完政策后要在 AGC「隐私管理服务」里**重新粘贴全文**，再提交审核。

> **打回经验（2026-10-13 实测）**：「标准化隐私声明托管」的系统弹窗依赖**应用市场云侧上架记录**，未上架（含审核中、被驳回）时**不弹**（faqs-appgallery-67）——审核员首启看不到任何隐私提示，被以「未明确提示用户阅读隐私政策」（审核指南 7.5）打回。
> 解法是提审前**先发邀请测试**建立云侧记录（`docs/AGC-SUBMIT.md` 第一节第 6 步），并先按第四节清单在真机上验证（隐私管理服务不支持模拟器）。
> 托管期间 App 侧**不得**自建弹窗：托管 + 自建会双弹窗被驳回（faqs-appgallery-84），两者只能选一。
