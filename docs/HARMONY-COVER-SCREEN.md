# 外屏适配验证

当前实现按实际窗口尺寸选择布局：高度不超过 480vp 时使用紧凑控制布局，且宽度也不超过 480vp 时隐藏控制页顶部状态栏。底部系统手势区保留；进入设置、发现或调试页恢复状态栏，返回控制页重新隐藏。未修改应用包名、最低系统版本或外屏准入配置。

紧凑布局减少提示文案和图标；键盘打开时隐藏页头和语音浮件，保留触摸区、文本输入与横向键条。窗口尺寸变化会取消旧触摸序列、释放按键并取消语音会话，键盘草稿仍由同一组件持有。发现页和重命名表单支持滚动，确认码栏可按可用宽度收缩。

## 已验证

| 环境 | 结果 |
| --- | --- |
| API 26 自定义 Phone 模拟器，980×980px / 480dpi（约 326.7vp 方形窗口） | 控制页状态栏从 117px 降为 0，增加 39vp 高度；连接按钮与键盘入口不重叠；设置、发现页恢复状态栏，返回控制页重新隐藏 |
| 同一方形窗口 | 输入文本、横向滑动键条和“收起”可操作；发现页空态、重新扫描、手动配对输入与按钮可以滚达 |
| API 26 Pura90API26 普通手机模拟器 | 状态栏保留；实际软键盘弹出后文本框、横向键条与收起按钮可操作 |
| 本地逻辑与协议验证 | `node tools/etstest/run.mjs .`：17 个文件、194 例通过；`node tools/prototest/run.mjs`：40 例通过；`devecocli build` 成功 |

方形 Phone 模拟器仅验证窗口几何，不等同于 Pura X 外屏设备。其输入法窗口实测仅高 1px，且底部节点命中边界存在裁切；已按真实键盘高度保留剩余系统手势区避让，但不能据此确认真实外屏软键盘表现。

## 真机调试状态与待验收

Pura X 典藏版已确认合盖后的屏幕为 980×980px。首次调试时，系统阻止应用显示并提示“请展开手机使用”；日志记录 `isBlockApp com.zhimingcool.padlink ret = true` 和 `is not outer trust App`。

随后已通过设置页面确认“外屏应用调试”开启，桌面进程也收到 `debug.outer.app` 更新，但立即启动及内屏合盖续用仍被拦截。用户重启手机后确认外屏调试可用，并已手动测试当前应用。本轮未由代理复测重启后的真实外屏交互，不能将此前拦截结论视为开启调试后的永久限制。

当前未添加额外的外屏支持声明；设备安装信息确认应用为 debug 版。开发调试可用不等于正式外屏准入审核已通过。

以下仍待实际设备或相应场景验证：

- 重启后外屏冷启动、展开/合盖连续切换、触摸板、多指手势与实际软键盘的逐项自动化取证。
- 小窗口中的完整确认码配对、重命名保存，以及语音识别卡片的长内容滚动。
- 深色模式、大字体与外屏读屏体验。
