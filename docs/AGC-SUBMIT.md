# AppGallery 上架操作手册（口袋键鼠）

> App 侧合规改造已完成（见本文档第三节）；**剩余事项全部是开发者账号侧行政流程，只有账号本人能办**。按顺序执行，标注 ⏱ 的有外部等待周期，建议最先启动。

## 一、你（账号本人）要办的事

### 1. ⏱ 华为开发者账号 + 个人实名认证

- 注册地址：developer.huawei.com → 账号中心 → 实名认证（个人主体）。
- 一个主体只能认证一个账号（faqs-appgallery-55）。
- 个人主体限制：无法用华为账号一键登录等企业能力——本应用不需要，无影响。

### 2. ⏱ AGC 创建应用

- AppGallery Connect → 创建应用：**名称「口袋键鼠」**、平台 HarmonyOS、包名 `com.zhimingcool.padlink`（须与 app.json5 一致）、设备 phone。
- 应用名称、包名将来必须与软著证书、备案信息完全一致——名称已定「口袋键鼠」，不要改。

### 3. ⏱ 版权证书（三选一，faqs-appgallery-3）

- 《计算机软件著作权登记证书》/《APP 电子版权认证证书》/《软件著作权认证证书》任一即可；**APP 电子版权认证证书办理最快**，软著常规 30+ 工作日。
- 软件名称必须填「口袋键鼠」，主体 = 你的实名主体；现在就去办，这是全流程最长的等待项。

### 4. 发布证书 + 发布 Profile（faqs-appgallery-19/-97）

- AGC「证书、APP ID 与 Profile」→ 申请**发布证书**（.cer）与**发布 Profile**（.p7b）。调试证书不能上架。
- API 26 的 DevEco `Build > Upload Product` 支持云端重签直传（需中国境内账号）。
- 发布证书 3 年有效；到期前记得换发，否则影响在架版本。

### 5. AGC 配置「标准化隐私声明托管」

- 位置：AGC → 我的项目 → 应用 → 「隐私管理服务」/发布页隐私声明区块，选择**托管**模式，把 `PRIVACY.md` 全文粘贴为政策文本。
- ⚠️ 选了托管就**不要再自建隐私弹窗**（App 侧已按托管模式实现，见第三节）。
- AGC「数据披露」表格：本应用全部可勾「不收集」。权限填报：麦克风用途照抄 `mic_permission_reason`。

### 6. 备案：按「单机应用」豁免申报

- AGC 备案信息中勾选**单机应用**（不连公网提供信息服务）豁免（faqs-appgallery-32）——本应用无任何云端服务器，符合豁免。
- 服务器信息如实填「无」。豁免通过则**无备案号，也无应用内展示义务**。
- 将来若加任何云功能，豁免即失效，需走完整备案（5–25 工作日）。

### 7. 录演示视频（审核可用性，关键）

App 必须配合 PC 端 daemon 才有功能，审核员环境里没有——**必须**用审核备注 + 视频补齐可用性证明，否则大概率以「功能不可用」拒审。分镜脚本见附录 A。

### 8. 提审

- 打 Release .app 包（发布证书签名）→ AGC 上传 → 填版本信息 → 分发范围**仅中国大陆**（UIDesignKit 组件仅境内支持，ui-design-introduction）→ 年龄分级问卷 → 审核备注粘贴附录 B → 提交。

## 三、App 侧合规实现（已完成，改动记录）

1. **隐私签署门控**（`VoiceModel.ensurePrivacyConsented`）：申请麦克风权限前先 `privacyManager.getAppPrivacyResult()` 查 AGC 托管签署状态；未同意则 `requestAppPrivacyConsent` 拉起标准化弹窗，同意后才走权限弹窗（store-privacy：未签署时系统必拒权限申请）。服务不可达（模拟器 / 侧载未托管）放行，不阻断开发链路。
2. **设置页隐私政策入口**（`SettingsPage.openPrivacyPolicy`）：`getAppPrivacyMgmtInfo()` 取托管链接，`openLink` 拉起浏览器；不可达时回落仓库 `PRIVACY.md`（与本文件同源）。
3. **首启隐私弹窗**：AGC 托管模式下由系统自动弹出，App 侧**禁止**自建（store-privacy 硬约束）——无需开发。

## 附录 A：演示视频分镜（约 60 秒）

1. **电脑端**（5s）：Ubuntu 桌面 + 终端执行 `systemctl --user status padlink` 显示 active (running)。
2. **配对**（10s）：手机发现页列出电脑 → 点击 → 电脑弹确认码 → 手机输码 → 显示已连接。
3. **触摸板**（15s）：手机触摸面滑动，电脑光标连续移动；两指滚动页面；双指轻点=右键菜单。
4. **键盘**（10s）：三指滑到键盘区，打「你好 PadLink」，电脑文本编辑器上屏。
5. **语音**（10s）：切语音区，按住说一句，松手后文字上屏电脑。
6. **三指切换 + 设置**（5s）：三指滑动三区轮转；设置页灵敏度滑杆实时生效。
7. 片尾（5s）：GitHub Releases 下载地址字卡。
