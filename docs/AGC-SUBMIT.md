# AppGallery 上架操作手册（口袋键鼠）

> App 侧已按**标准化隐私声明托管**模式就位（见第三节）；**剩余事项为真机验证（第四节）与开发者账号侧行政流程（只有账号本人能办）**。按顺序执行，标注 ⏱ 的有外部等待周期，建议最先启动。

## 一、你（账号本人）要办的事

### 1. ⏱ 华为开发者账号 + 个人实名认证

- 注册地址：developer.huawei.com → 账号中心 → 实名认证（个人主体）。
- 一个主体只能认证一个账号（faqs-appgallery-55）。
- 个人主体限制：无法用华为账号一键登录等企业能力——本应用不需要，无影响。

### 2. ⏱ AGC 创建应用

- AppGallery Connect → 创建应用：**名称「口袋键鼠」**、平台 HarmonyOS、包名 `com.zhimingcool.padlink`（须与 app.json5 一致）、设备 phone。
- 应用名称、包名将来必须与软著证书、备案信息完全一致——名称已定「口袋键鼠」，不要改。

### 3. ⏱ 版权证书（三选一，faqs-appgallery-3）

- 《计算机软件著作权登记证书》/《APP 电子版权认证证书》/《软件著作权认证证书》任一即可；**APP 电子版权认证证书办理最快**，软著常规 30+ 工作日。
- 软件名称必须填「口袋键鼠」，主体 = 你的实名主体；现在就去办，这是全流程最长的等待项。

### 4. 发布证书 + 发布 Profile（faqs-appgallery-19/-97）

- AGC「证书、APP ID 与 Profile」→ 申请**发布证书**（.cer）与**发布 Profile**（.p7b）。调试证书不能上架。
- API 26 的 DevEco `Build > Upload Product` 支持云端重签直传（需中国境内账号）。
- 发布证书 3 年有效；到期前记得换发，否则影响在架版本。

### 5. AGC 配置「隐私托管」（模板生成，**不是粘贴全文**）

托管模式下政策文本由 AGC **标准化模板逐模块生成**，开发者按实际情况填表即可，无需自备全文。两步：

1. **生成政策**：HarmonyOS 开发者中心 → 应用管理 → 选中应用 → 左侧「**分发 > 更多服务 > 协议服务**」→「新建协议」→ 协议类型选「**隐私政策**」→ 填协议名称与默认语言 → 逐模块编辑（模块清单 + 本项目逐模块填法见 `docs/AGC-MATERIALS.md` 第五节）→ 右上角「预览」确认 →「**生成协议**」（状态变「完成」；只「保存」则为草稿，仅允许一个草稿）。
   - 适用条件：发布地区包含中国大陆、分发设备为手机 / 平板 / PC 2in1（本项目符合）；每个应用最多 300 个政策，上线**仅关联 1 个**。
2. **关联到版本**：左侧「**应用上架 > 版本信息**」→ 待发布版本 → 「**隐私声明**」区域选「**隐私托管**」→ 选中刚生成的政策。

- ⚠️ **「设备权限调用」模块必须与包内 `requestPermissions` 完全一致**（勾选的权限项 + 填写的作用），否则无法提交审核——2026-10-12「权限与隐私声明不一致」那次打回，真正的修复位置就是该模块（faqs-appgallery-7 第 3–4 步），而不是改仓库里的 `PRIVACY.md`。
- 备选路线：若改用「**自定义隐私政策**」，需填「隐私政策网址」与「隐私权利」两个网址，且 App 侧**必须自建首启弹窗**——这与本项目已选的托管路线互斥，两者并存会双弹窗被驳回（faqs-appgallery-84）。
- ⚠️ 选了托管就**不要再自建隐私弹窗**（App 侧自建弹窗已移除，见第三节）。
- 仓库 `PRIVACY.md` 的定位：应用内可读副本、设置页兜底链接、未上架真机验证时预置 URL 的内容源（见第三节第 4 条）——**不是** AGC 托管文本的来源。
- 提审界面的数据收集 / 权限填报按 `docs/AGC-MATERIALS.md` 第五、六节填。

### 6. ⏱ 先发「邀请测试」建立云侧隐私记录（关键，勿跳过）

- **为什么**：托管模式的标准化隐私弹窗依赖**应用市场云侧上架记录**，而「审核中 / 被驳回」**不算上架**（faqs-appgallery-67）——2026-10-13 首次提审即因审核员首启看不到任何隐私提示，被以「未明确提示用户阅读隐私政策」（审核指南 7.5）打回。邀请测试属于文档认可的「上架」类型之一，先发一次即建立该记录。
- **怎么做**：AGC「应用测试」→ 创建邀请测试 → 上传**发布证书签名**的包（调试证书包不能用于测试分发，faqs-appgallery-49）→ 通过检测后发布 → 用自己的华为账号安装一次。
- **验收**：从应用市场安装后首次启动**能弹标准化隐私弹窗**；随后对同一包用 hdc 安装也仍能弹（faqs-appgallery-67 第 2 问）。验收步骤见第四节。
- 测试与生产是**不同上架通道**（faqs-appgallery-71）：先走测试通道建立记录，再走正式提审；两者版本号是否需要不同，以 AGC 上传时的实际提示为准。

### 7. 备案：按「单机应用」豁免申报

- AGC 备案信息中勾选**单机应用**（不连公网提供信息服务）豁免（faqs-appgallery-32）——本应用无任何云端服务器，符合豁免。
- 服务器信息如实填「无」。豁免通过则**无备案号，也无应用内展示义务**。
- 填报要点与说明话术（可直接粘贴）：见 `docs/AGC-MATERIALS.md` 第四节。
- 将来若加任何云功能，豁免即失效，需走完整备案（5–25 工作日）。

### 8. 录演示视频（审核可用性，关键）

App 必须配合 PC 端 daemon 才有功能，审核员环境里没有——**必须**用审核备注 + 视频补齐可用性证明，否则大概率以「功能不可用」拒审。细化分镜（可直接照拍）见 `docs/AGC-MATERIALS.md` 第十节。

### 9. 提审

- 打 Release .app 包（发布证书签名）→ AGC 上传 → 填版本信息 → 分发范围**仅中国大陆**（UIDesignKit 组件仅境内支持，ui-design-introduction）→ 年龄分级问卷 → 审核备注粘贴附录 B（增强版见 `docs/AGC-MATERIALS.md` 第九节）→ 提交。
- 提审各字段的可粘贴内容（一句话简介 / 应用介绍 / 应用截图 / 权限与数据披露 / 年龄分级 / 版本更新说明）统一在 **`docs/AGC-MATERIALS.md`**，截图文件在 `docs/agc/screenshots/`。

### 版本号规则

- `versionName` 与 git tag 对齐（`v1.2.0` ↔ `1.2.0`）；`versionCode = major×1e6 + minor×1e4 + patch×1e2`（1.2.0 → 1020000）。

## 三、App 侧合规实现（托管模式）

1. **隐私签署门控**（`VoiceModel.ensurePrivacyConsented`）：申请麦克风权限前先 `privacyManager.getAppPrivacyResult()` 查托管签署状态；未同意则 `requestAppPrivacyConsent` 拉起标准化弹窗，同意后才走权限弹窗（store-privacy：未签署时系统必拒权限申请）。服务不可达（模拟器 / 侧载未托管）放行，不阻断开发链路；模式变更无需改代码。
2. **设置页隐私政策入口**（`SettingsPage.openPrivacyPolicy`）：`getAppPrivacyMgmtInfo()` 取托管链接，`openLink` 拉起浏览器；不可达时回落仓库 `PRIVACY.md`（与本文件同源）。
3. **首启隐私弹窗**：托管模式下由系统统一弹出，App 侧**禁止**自建（store-privacy 硬约束）。
   - ⚠️ 该弹窗依赖**应用市场云侧上架记录**，未上架（含审核中、被驳回）时不弹——2026-10-13 提审即因此被以「首次启动未提示阅读隐私政策」打回。解法是**提审前先发邀请测试**（第一节第 6 步）建立记录，而不是在 App 侧补弹窗。
   - 曾按「自建首启弹窗 + AGC 自定义隐私政策」做过一版，因与托管模式互斥（托管+自建双弹窗会被驳回，faqs-appgallery-84）已整体回退；存档在 git 分支 `backup/self-built-privacy-popup` 与对应 stash。
4. **上架前本地验证的调试预置**（store-privacy「未上架应用接入隐私管理服务」）：`entry/src/main/module.json5` 的 module 级 metadata 已加 `appgallery_privacy_hosted=1` 与 `appgallery_privacy_link_privacy_statement`（指向仓库 `PRIVACY.md` 的 https 地址，与 `privacy_fallback_url` 同值）。官方按「未上架应用测试用」描述、示例以 debug 构建演示，但 2026-10-14 真机实测确认 **release 模式同样生效**（去掉预置则同包不弹），因此它不只是测试工具，也是审核期弹窗的兜底——提审包去留见第四节 B/C 组结论。

## 四、上架前真机验证清单（隐私管理服务不支持模拟器，必须真机）

前置：真机（HarmonyOS NEXT）+ hdc + 华为应用市场可用且联网。

| 组 | 步骤 | 预期 |
| --- | --- | --- |
| **A. 调试预置**（无云侧记录，验 App 侧接入） | 1. debug 构建 → hdc 安装 → 首次启动 | 弹**标准化**隐私弹窗（系统统一弹窗，非 App 自绘），内容取自预置 URL |

> ⚠️ **实测注意**：标准化隐私弹窗**不接受注入点击**（`devecocli ui click` 与 `uinput -T -c` 点「同意」「取消」均无效，日志始终 `no privacy result`），但注入系统键（HOME）有效——属系统防自动同意，非坐标问题。故该弹窗的按钮与政策链接**只能真人点按**：本次由用户手工完成，链接可打开政策全文（GitHub 加载正常）。

## 附录 A：演示视频分镜（约 60 秒）
